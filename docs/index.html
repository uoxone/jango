Django, written in Rust

OnGo

A Django-style web framework, written in the Rust programming language. You keep a short list of paths, each path calls a function, and the HTML lives in a template.

When the pages feel right, one file is the whole server. The standard library is the only dependency.

  1. 01 Start Install the command and open nava.
  2. 02 Routes The map of the site, one line per page.
  3. 03 Views A request comes in. A response goes out.
  4. 04 Templates A shared page, and a quiet place for each value.
  5. 05 Static CSS, pictures, video, and other files from one folder.
  6. 06 Ship Build one file and let it listen.
  7. 07 Tests How to know the framework still holds.

Is there a Django written in Rust?

Yes. OnGo is that shape: projects, URLs, views, templates, and static files, written in Rust. Install it with cargo install ongo, then follow the start guide.

Is OnGo the Django project itself?
OnGo is its own framework. The ideas match Django. The language is Rust, and the result is one executable.
How do I install it?
cargo install ongo, then ongo create project nava and ongo run nava. The server is at http://127.0.0.1:8000.

Stage 1 is projects, URLs, views, templates, static files, and the HTTP server.

A database, admin, middleware, chunked bodies, and IPv6 are waiting for a later stage.

A small framework, written to stay small.
