Dingo documentation

Dingo is a small TypeScript web framework. When Bun is installed, the server uses Bun.serve. Otherwise it uses node:http on Node.

These pages are static HTML. There is no generator, Markdown source, or build step. Open the file in a browser. A Markdown toolchain can wait until the docs are large enough to need one.
