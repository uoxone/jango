Start

Open a project

Two commands create the app. A third one puts it in the browser.

Install the command

cargo install ongo

cargo install ongo places ongo on your PATH, usually at ~/.cargo/bin/ongo.

Create and run

ongo create project nava
ongo run nava

The server is at http://127.0.0.1:8000. ongo run compiles a development build, so you can keep editing views.

Inside the project folder, the name is optional:

cd nava
ongo run

A name starts with a letter. After that, letters, digits, _, and - are welcome. nava, my_nava, and my-nava are all fine.

What you get

nava/ Cargo.toml build.rs src/main.rs src/settings.rs src/urls.rs src/views.rs static/css/style.css templates/page.html templates/home.html templates/about.html

src/urls.rs is the map. src/views.rs is the functions. templates/ is the HTML. static/ holds CSS, pictures, video, and other files. build.rs folds the templates into the binary. The static folder stays on disk.

The address

src/settings.rs holds the listen address:

pub const ADDR: &str = "127.0.0.1:8000";
pub const STATIC_URL: &str = "/static/";
pub const STATIC_DIR: &str = "static";

127.0.0.1 is this machine. When you run the binary on a server, change it to 0.0.0.0:8000. Ongo listens on IPv4. STATIC_URL is the public prefix. STATIC_DIR is the folder. static/css/style.css is served at /static/css/style.css.

Useful commands

CommandWhat it does
ongo create project <name>Writes a new project in ./<name>
ongo run [name]Compiles and serves a development build
ongo run [name] --releaseServes the optimized build
ongo build [name]Writes build/<name> and build/static
ongo --helpShows the commands
ongo --versionPrints the version

Prefer to skip the install while you are in this repository? This works too:

cargo run -- create project nava
cargo run -- run nava
