Start

From the Dingo directory, these two commands create a project and run it.

./bin/dingo create project mehrashop
./bin/dingo run mehrashop

The project contains settings.ts, url.ts, and a small package.json with "type": "module". No HTML file is written into the project.

const settings = {
  host: "127.0.0.1",
  port: 8000,
}

export default settings

Force Node with:

DINGO_RUNTIME=node ./bin/dingo run mehrashop

If port 8000 is already taken, the server does not start. Stop the other process, or change port in settings.ts. Restart the server after you edit a file.

Dingo listens once per CPU core. Set DINGO_WORKERS=1 to use a single listener.
