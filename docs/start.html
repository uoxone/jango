Start

Open a project

Two commands create the app. A third one puts it in the browser.

Install the command

From the OnGo repository:

cargo install --path .

That builds this folder and places ongo on your PATH, usually at ~/.cargo/bin/ongo.

From a fresh clone

git clone https://github.com/uoxone/jango.git
cd jango
cargo install --path .

Create and run

ongo create project nava
ongo run nava

The server is at http://127.0.0.1:8000. ongo run compiles a development build, so you can keep editing views.

Inside the project folder, the name is optional:

cd nava
ongo run

A name starts with a letter. After that, letters, digits, _, and - are welcome. nava, my_nava, and my-nava are all fine.

What you get

nava/ Cargo.toml build.rs src/main.rs src/settings.rs src/urls.rs src/views.rs templates/page.html templates/home.html templates/about.html

src/urls.rs is the map. src/views.rs is the functions. templates/ is the HTML. build.rs folds those templates into the binary, so the running server carries its pages with it.

The address

src/settings.rs holds the listen address:

pub const ADDR: &str = "127.0.0.1:8000";

127.0.0.1 is this machine. When you run the binary on a server, change it to 0.0.0.0:8000. Ongo listens on IPv4.

Useful commands

CommandWhat it does
ongo create project <name>Writes a new project in ./<name>
ongo run [name]Compiles and serves a development build
ongo run [name] --releaseServes the optimized build
ongo build [name]Writes the file you upload
ongo --helpShows the commands
ongo --versionPrints the version

Prefer to skip the install while you are in this repository? This works too:

cargo run -- create project nava
cargo run -- run nava
