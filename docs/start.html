Start

Install the command

bun install -g @uoxone/jango
# or
npm install -g @uoxone/jango

Link the command

If you download the repository from GitHub, use these commands instead:

git clone https://github.com/uoxone/Jango.git
cd Jango
bun link

bun link takes no package name. It registers this folder and installs the jango command.

From this directory, remove that link:

bun unlink

Create and run

jango create project mehrashop
jango run mehrashop

The server is at http://127.0.0.1:8000.

With no arguments, jango prints:

Usage:
  jango create project <name>
  jango run [dir]
  jango -v

jango -v prints the version. jango --version does the same.

jango run serves the current directory. jango run mehrashop serves that folder.

Project files

The project contains settings.ts, url.ts, and a package.json with "type": "module". No HTML file is written into the project.

const settings = {
  host: "127.0.0.1",
  port: 8000,
}

export default settings

The server prints Jango bun http://127.0.0.1:8000. Restart it after you edit a file.

Names

A project name starts with a letter and uses only letters, numbers, _, or -. It can be at most 64 characters. Creating the same name again fails with Project already exists.

Port

If port 8000 is already taken, the server does not start. Stop the other process, or change port in settings.ts.

Workers

Jango listens once per CPU core. Set JANGO_WORKERS=1 to use a single listener.
