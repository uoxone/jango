Start

Bun 1.1 or newer is required. Clone the repository, or extract the GitHub ZIP and enter that directory, then link the command:

git clone https://github.com/uoxone/Dingo.git
cd Dingo
bun link dingo

bun link dingo installs the dingo binary. Open a new terminal. From any directory:

dingo create project mehrashop
dingo run mehrashop

With no arguments, dingo prints:

Usage:
  dingo create project <name>
  dingo run [dir]

dingo run serves the current directory. dingo run mehrashop serves that folder.

Project files

The project contains settings.ts, url.ts, and a package.json with "type": "module". No HTML file is written into the project.

const settings = {
  host: "127.0.0.1",
  port: 8000,
}

export default settings

The server prints Dingo bun http://127.0.0.1:8000. Restart it after you edit a file.

Names

A project name starts with a letter and uses only letters, numbers, _, or -. It can be at most 64 characters. Creating the same name again fails with Project already exists.

Port

If port 8000 is already taken, the server does not start. Stop the other process, or change port in settings.ts.

Workers

Dingo listens once per CPU core. Set DINGO_WORKERS=1 to use a single listener.
