Tests

See that it holds

The tests keep the framework honest. Run them in the OnGo repository, before you trust a change.

Run them

cargo test

A good run ends in ok. You get the framework tests, the ongo command tests, and the doc test.

A smaller slice:

cargo test --lib           # framework
cargo test --bin ongo     # create, run, build
cargo test template        # tests with template in the name
cargo test -- --list       # names only

Where they live

The cases are in core/tests/, one file for each part. The source in core/src/ stays the implementation. Each file points at its tests with a short #[path] link, so a test can still see the private functions it needs.

core/tests/ http.rs parse.rs router.rs template.rs static.rs server.rs sys.rs routes.rs cli.rs

What they hold

FileIt checks
http.rsMethods, query, headers, parameters, and responses
parse.rsReading an HTTP request, including a body and keep-alive
router.rsExact paths, <id>, and routes that should be refused
routes.rsThe routes! macro
template.rs{{ }}, blocks, extends, static, and the sample pages
static.rsThe static folder, content types, and paths that stay refused
server.rsResponse headers, and a real server on 127.0.0.1
sys.rsThe listen socket and the epoll layout
cli.rsongo create project and the command checks

One server test listens on 127.0.0.1. The rest stay inside the process. Run cargo test here, in the framework repository.
