Tests

From the Jango repository:

bun test

The test directory checks project creation, the default page, route functions, HTML files, 500 responses, 404 responses, and routes that try to leave the project.

Temporary files live under test/.tmp and are removed after each test. The test server binds to port 0, so it does not collide with a dev server on port 8000.
