Templates

A page, and a shell

HTML lives in templates/. A view asks for a file by name. The values you pass are escaped, so a name cannot become markup.

Ask for a page

pub fn home(req: &Request) -> Response {
    render!(req, "home.html", {
        "addr" => settings::ADDR,
    })
}

pub fn about(req: &Request) -> Response {
    render!(req, "about.html")
}

Each value is a string. In the file, {{ addr }} prints it. A name you forgot is simply empty. {{ request.path }} and {{ request.method }} come from the request itself.

These five characters are escaped: & < > " '. The markup you wrote in the file stays as you wrote it.

One shell for every page

page.html is the frame. home.html fills the open spaces.

<title>{% block title %}{% endblock %}</title>
<main>
{% block content %}{% endblock %}
</main>
{% extends "page.html" %}

{% block title %}nava · OnGo{% endblock %}

{% block content %}
<h1>nava</h1>
<p>Listening on {{ addr }}.</p>
{% endblock %}

{% extends %} is the first tag. Blank lines and {# comments #} may sit above it. Single quotes work too: {% extends 'page.html' %}.

A child replaces blocks by name. The deepest child wins. Words in the child that sit outside a block are left out, so the shell stays in charge of the page. {% endblock %} may repeat the block name, or leave it out.

build.rs reads templates/*.html and embeds them. After a change, the next ongo run picks the new files up. The server you ship already contains the pages.

A piece from another file

{% include "nav.html" %} renders that file and places the HTML here. The included file sees the same values, including {{ name }} and {{ request.path }}. Single quotes work too: {% include 'nav.html' %}.

nav.html is the small piece. The page pulls it in.

<a href="/">{{ name }}</a>
{% extends "page.html" %}

{% block content %}
{% include "nav.html" %}
<h1>{{ name }}</h1>
{% endblock %}

The included file is its own page. It may {% extends %} a shell. A block inside it stays inside it, and does not fill a block in the page that included it. If a child replaces a block, an include inside the old block is left out.

A file in static/

{% static "css/style.css" %} prints the public path. With STATIC_URL set to /static/, the tag becomes /static/css/style.css. The bytes stay in the static/ folder. Static is where that folder is served.

When a template is unhappy

A problem becomes a 500 response with a short reason. The usual ones:

SituationWhat you see
The file is missingwas not found
A template extends itself, even through a loopextends itself
The extends chain is deeper than 16extends too deep
A template includes itself, even through another fileincludes itself
The include chain is deeper than 16include too deep
An unknown tag, such as {% if %}unknown tag
