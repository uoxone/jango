Routes

url.ts exports the routes. Until / is defined, Dingo shows its built-in “It works” page. That page is not a file in the project.

const url = {
  "/": () => "Hello",
  "/about": () => "<h1>About</h1>",
}

export default url

A handler may return a Promise. An HTML string can also be read from a file inside the project. The file is loaded once when the server starts and then served from memory:

const url = {
  "/": "page.html",
}

export default url

The file name must end in .html and must stay inside the project directory. An unknown path returns 404. The query string is stripped, so /?x=1 is the same route as /.
