Routes

url.ts default-exports the routes. Every path starts with /. A route is a function or an .html file name.

const url = {
  "/": () => "Hello",
  "/about": () => "<h1>About</h1>",
}

export default url

A handler may return a Promise. The response is HTML (text/html; charset=utf-8).

HTML files

An HTML string can also be read from a file inside the project. The file is loaded once when the server starts and then served from memory:

const url = {
  "/": "page.html",
}

export default url

The file name must end in .html, must not start with /, and must stay inside the project directory. .. is rejected. A missing file fails at startup with Missing page.html.

Default page

Until / is defined, Jango shows its built-in “It works” page. That page is not a file in the project. It includes the project folder name.

Status

An unknown path returns 404 and the text Not Found. The query string is stripped, so /?x=1 is the same route as /.

If a handler throws, or a returned promise rejects, the response is 500 and the text Internal Server Error.

A directory without settings.ts and url.ts is not a Jango project. settings.ts must default-export { host, port }.
