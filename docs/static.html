Static

One folder, one URL

CSS, pictures, video, and other files live in static/. The browser asks for them at STATIC_URL.

Settings

pub const STATIC_URL: &str = "/static/";
pub const STATIC_DIR: &str = "static";

main.rs hands both to the router:

let app = urls::urlpatterns()
    .templates(templates::load)
    .staticfiles(settings::STATIC_URL, settings::STATIC_DIR);

static/css/style.css is then /static/css/style.css. A picture is static/img/cover.jpg. A video is static/video/clip.mp4. The URL can be /media/ if you would rather call it that. It starts and ends with /.

Inside a page

<link rel="stylesheet" href="{% static "css/style.css" %}">
<img src="{% static "img/cover.jpg" %}" alt="Cover">

The tag joins STATIC_URL and the path. The path is relative: css/style.css, not /css/style.css and not ../secret. Quotes may be single or double. The value is escaped, the same way as {{ name }}.

static/ css/style.css img/cover.jpg video/clip.mp4

A new project already has static/css/style.css. The sample page links it. Edit the file and refresh. A static file is read from disk, so it does not need another build. Templates still do.

What comes back

GET and HEAD serve the file. Another method is 405. A missing file, a directory, or a path that tries to leave the folder is 404. That 404 does not fall through to a view, and it does not use your not_found page. A path outside the prefix, such as /about, is still a normal route.

The extension chooses the type: .css, .js, pictures (.png, .jpg, .gif, .webp, .svg), video (.mp4, .webm), audio, and fonts. Anything else is sent as raw bytes, so an unknown file still downloads. A video may ask for a byte range. OnGo answers with the slice.

On the server

ongo build copies static/ to build/static, beside the program. Run the program from that folder. OnGo looks in the current directory first, then next to the program. Set STATIC_DIR to an absolute path when the folder lives somewhere else.
