## 🌿 Install the command

From this folder:

```bash
cargo install --path .
```

## 🌿 From a fresh clone

```bash
git clone https://github.com/uoxone/jango.git
cd jango
cargo install --path .
```

`cargo install --path .` builds this folder and puts the `jango` command on your PATH.

## ✨ Create and run

```bash
jango create project nava
jango run nava
```

The server is at `http://127.0.0.1:8000`.
