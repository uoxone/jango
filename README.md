## 🌿 Link the command

```bash
git clone https://github.com/uoxone/Dingo.git
cd Dingo
bun link dingo
```

## ✨ Create and run

```bash
dingo create project mehrashop
dingo run mehrashop
```

The server is at `http://127.0.0.1:8000`.

## 🚀 Git commit guidelines

| Prefix | When |
| --- | --- |
| ✨ `feat:` | a new feature |
| 🔧 `fix:` | a bug fix |
| ♻️ `refactor:` | a change that does not add a feature or fix a bug |
| 🗑️ `remove:` | code or packages removed |
