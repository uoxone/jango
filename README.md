## 🌿 Install the command

```bash
cargo install ongo
```

`cargo install ongo` puts the `ongo` command on your PATH.

## ✨ Create and run

```bash
ongo create project nava
ongo run nava
```

The server is at `http://127.0.0.1:8000`.
