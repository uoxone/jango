Jango {{ name }} Docs

It works.

The server is running. You see this page because / is not defined in url.ts.

Simple

Put the page in templates/page.html. Point / at that file, then restart the server.

const url = {
  "/": "page.html",
}

export default url

Static

staticRoot is the folder. staticUrl is the address. With the defaults, static/css/app.css is served at /static/css/app.css. Restart the server after you change a file.

Complete

url.ts default-exports the routes. Every path starts with /. A string is a template name, and that file must live in templates/. The name page.html loads templates/page.html. A file next to url.ts is not a template. Jango reads the file once at startup and then serves it from memory.

A name may include a subdirectory, such as blog/post.html. It must end in .html and must not start with /. .. is rejected. A missing file stops startup with Missing template: page.html.

A route can also be a function. It may return a string or a Promise. The response is HTML.

const url = {
  "/": () => "Hello",
}

export default url

Restart the server after you change a file. A path that is not listed returns 404 and the text Not Found. If a handler throws, the response is 500.
